# Smart Code Complexity Analyzer

A web-based tool that analyzes code and estimates time complexity using pattern-based logic.

##  Features
- Detects loops and nested loops
- Estimates time complexity (O(n), O(n²), etc.)
- Detects recursion and sorting
- Provides optimization insights

##  Tech Stack
- Python
- Flask
- HTML, CSS

##  How to Run
pip install flask
python app.py
